🎵 Spotify Web Player UI Clone
A responsive Spotify Web Player user interface clone built using HTML5 and CSS3.
This project focuses on layout, styling, and responsiveness and does not include real music playback or backend functionality.

🚀 Features
🎧 Spotify-like modern UI
📂 Sidebar with Home, Search, and Library
📊 Recently Played, Trending, and Featured Charts sections
🎶 Music Player bar at the bottom
📱 Responsive design (basic mobile support)
🎨 Custom fonts and icons

🛠️ Technologies Used
HTML5
CSS3
Font Awesome Icons
Google Fonts (Montserrat)
Material Symbols Icons

⚙️ How to Use This Project
1️⃣ Clone or Download the Repository
git clone https://github.com/kaimharsh/Spotify_clone.git
OR download the ZIP file and extract it.

2️⃣ Open the Project
Open the project folder
Double-click index.html
OR open it using Live Server in VS Code (recommended)

3️⃣ View in Browser
The UI will open in your default browser and display:
Sidebar navigation
Music cards
Bottom music player

❗ Important Notes
🚫 This project is UI only
🎵 No real audio playback
🔐 No login or authentication
🌐 No backend or JavaScript logic

This project is meant for:
Frontend practice
CSS layout & Flexbox learning
UI cloning practice
